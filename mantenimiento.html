🔧 Mantenimiento del Sistema

⚠️ Advertencia

Las operaciones de mantenimiento pueden modificar datos en la base de datos. Asegúrate de entender lo que hace cada función antes de ejecutarla.

🔧 Seleccionar Operación

🔍 Verificación de Integridad

Verifica la consistencia de los datos sin realizar cambios.

🔧 Reparación Automática

Repara automáticamente problemas detectados (totales incorrectos, estados inconsistentes).

🔄 Recalcular Todos los Totales

Recalcula los totales pagados y saldos pendientes de todas las matrículas basándose en los pagos registrados.

🔄 Cambiar Código de Sección

Cambia el código de una sección existente.

💰 Corregir Monto Pagado

Busca una matrícula y corrige el monto total pagado.

💰 Corrección de Precios de Ventas

Corrige el precio de una venta ya registrada. Esto actualizará el total y recalculará el saldo pendiente.

📋 Logs del Sistema

Fecha Usuario Acción Tabla ID Registro Detalles
Haz clic en "Buscar" para cargar los logs

💾 Backup Manual

Crea una copia de seguridad de la base de datos actual.

Nota: Esta función crea una copia de la hoja de cálculo completa. Puedes acceder a tus backups desde Google Drive.

🗑️ Eliminar Venta Específica

Busca un alumno y elimina una venta completa (alumno, matrículas, pagos, cuotas, venta, eventos Calendar).

🔀 Corregir Sección de Matrícula

Mueve una matrícula a cualquier sección (sin restricción de curso). Para corregir errores de asignación.

🎯 Corregir Modalidad de Matrícula

Cambia la modalidad (Basic/Pro/Certify) de una matrícula. Ajusta precio, examen y simulador según corresponda.

📅 Editar Cuotas Programadas

Busca por ID de matrícula o nombre del alumno para ver y editar las cuotas programadas (montos y fechas).
